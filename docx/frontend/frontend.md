# 前端需求文档

## 项目概述

- **项目名称**：二次元画风猜谜小游戏（待定）
- **项目类型**：全栈Web应用 - 前端部分
- **核心功能**：玩家通过二次元风格的界面参与猜谜游戏

## 技术栈要求

### 核心技术
- **框架**：React 18+
- **构建工具**：Vite
- **语言**：TypeScript
- **状态管理**：Zustand / React Context
- **样式方案**：CSS Modules / Tailwind CSS / styled-components

### UI相关
- **动画库**：Framer Motion（可选）
- **图标库**：Lucide React / React Icons

## 功能需求

### 1. 首页/大厅
- 游戏标题展示（带二次元风格）
- 开始游戏按钮
- 排行榜入口
- 设置入口（音效开关等）

### 2. 游戏界面
- 题目展示区域
- 答案输入/选择区域
- 倒计时显示
- 得分显示
- 生命值/提示次数显示
- 下一题按钮

### 3. 结果页面
- 最终得分展示
- 正确答案回顾
- 重新开始按钮
- 返回首页按钮

### 4. 排行榜
- 显示玩家排名
- 显示历史最高分

### 5. 设置页面
- 音效开关
- 难度选择
- 主题切换（可选）

## UI/UX设计要求

### 视觉风格
- 二次元/动漫风格
- 使用柔和的配色方案
- 圆润的UI元素
- 动态背景或装饰元素

### 响应式设计
- 桌面端和移动端适配
- 触控友好的交互区域

### 交互动效
- 按钮悬停效果
- 页面切换动画
- 答案正确/错误的视觉反馈
- 倒计时紧迫感动画

## 性能要求

- 首屏加载时间 < 3秒
- 页面切换流畅无卡顿
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）

## 目录结构建议

```
src/
├── components/       # UI组件
├── pages/           # 页面组件
├── hooks/           # 自定义Hooks
├── store/           # 状态管理
├── services/        # API调用
├── styles/          # 全局样式
├── assets/          # 静态资源
└── utils/           # 工具函数
```
